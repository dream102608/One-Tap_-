## 三、整体技术路线与系统构成概述

### 3.1 技术路线

基于 ROS2 + 地平线 RDK 平台，采用"**视觉感知 → 决策控制 → 底盘执行**"的模块化分层架构：

- **感知层**：赛道识别、障碍物检测、二维码识别，并辅以激光雷达与云端大模型（图生文）能力；
- **决策控制层**：状态机统一调度，融合多路感知结果，实时输出速度与转向指令；
- **执行层**：底盘驱动与运动控制，实现自主巡线行驶。

### 3.2 系统构成

```
┌──────────────────────────────────────────────┐
│ 感知层                                        │
│  赛道识别 · 障碍物检测 · 二维码 · 图生文 · 雷达 │
└──────────────────┬───────────────────────────┘
                   ▼
┌──────────────────────────────────────────────┐
│ 决策控制层                                    │
│  状态机调度 · 巡线控制 · 避障控制              │
└──────────────────┬───────────────────────────┘
                   ▼
┌──────────────────────────────────────────────┐
│ 执行层 · 底盘驱动（origincar）                │
└──────────────────────────────────────────────┘
```

### 3.3 功能模块一览

| 模块 | 作用 |
| --- | --- |
| `origincar` | 底盘驱动、启动（图传/传感器）、消息定义 |
| `racing_track_detection_resnet_go/n/s/back` | 四路 ResNet 赛道识别节点（各配独立模型），输出巡线目标点 |
| `racing_obstacle_detection_yolo` | YOLO 障碍物检测，输出障碍物位置与类别 |
| `racing_control` | C++ 竞速控制节点，融合感知结果输出速度指令 |
| `control` | Python 控制主节点，状态机统一调度巡线/避障/停车 |
| `qrcode` | 二维码解码，发布方向与数字信息 |
| `image_analyzer` | 扫码触发拍照，调用云端大模型生成图像描述 |
| `voice_broadcast` | TTS 语音播报 |
| `my_Amcl` / `my_nav` | Nav2 定位与导航（备用方案） |
| `LSLIDAR_X_ROS2` | 激光雷达驱动（第三方） |

### 3.4 关键技术思路

- 多路模型分场景调用：不同赛段切换对应识别模型，提高鲁棒性；
- 状态机驱动控制流，避免多线程竞争，保证决策实时性；
- 感知结果与控制参数解耦，便于按场地实测标定。
